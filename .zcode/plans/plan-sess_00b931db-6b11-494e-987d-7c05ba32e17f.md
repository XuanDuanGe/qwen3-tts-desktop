## 发现

当前 `.gitignore` 已覆盖部分常见构建产物，但有两个问题：

- `samples/` 和 `docs/` 会忽略项目中应提交的示例源代码和文档。
- 未锚定的 `models/` 会错误匹配 `desktop/src-tauri/src/models/` 中的 Rust 源码；未来新增模型模块可能无法被 Git 发现。

## 最小完善方案

仅更新根目录 `.gitignore`：

1. 将 Node/Vite 生成物明确限定到工作区根与 `desktop` 包：依赖目录、构建目录和覆盖率目录。
2. 保留 Rust/Tauri 的实际构建产物忽略规则（`/desktop/src-tauri/target/` 与调试符号）。
3. 保留环境变量、日志、编辑器、操作系统与现有 Python 缓存忽略项。
4. 将运行时本地数据目录锚定到仓库根；根级模型文件只使用 `/models/`，不再误伤 Rust `src/models` 源码。
5. 移除 `samples/`、`docs/` 规则，确保项目示例与文档能被提交。
6. 不忽略 lockfile、Tauri schema/图标等应版本控制的项目文件。

完成后会通过 Git Bash 使用 `git check-ignore` 核验关键的“应忽略”和“不得忽略”路径，以及用 `git diff --check` 做静态检查；不会运行构建或测试。
