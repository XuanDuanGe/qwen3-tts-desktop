## 1. 新增共享自定义音频播放器

新增轻量组件：
- `desktop/src/renderer/src/components/AudioPlayer.jsx`

实现范围：
- 使用原生 `<audio ref>` 作为播放引擎，但隐藏浏览器默认 controls。
- 提供紧凑的自定义控制条：播放/暂停按钮、当前时间、可键盘操作的进度 range、总时长、音量按钮和音量 range。
- 从 `loadedmetadata`、`timeupdate`、`ended` 同步真实时长和进度；使用 `m:ss` 格式，加载前显示 `--:--`。
- `src` 切换时暂停并复位 UI；卸载时停止播放。无 autoplay。
- 所有控件设置明确的 `aria-label`；进度与音量均保留原生 range 的键盘操作能力。
- 样式只使用现有 Tailwind token：`panel/elevated/border/primary/text/text-muted` 等；无波形伪造、无渐变、无阴影。

替换两个原生 `<audio controls>`：
- `desktop/src/renderer/src/features/voice-generate/VoiceGeneratePage.jsx`
- `desktop/src/renderer/src/pages/AudioFilesPage.jsx`

下载仍放在两个页面现有的预览头部，避免播放器内重复下载入口。

## 2. 统一页面密度与卡片对齐

修改：
- `VoiceGeneratePage.jsx`
- `AudioFilesPage.jsx`
- `SettingsPage.jsx`
- `MessageHost.jsx`

做法：
- 统一页面容器为紧凑间距（以 8px 基准收敛至 12/16/24/32px 级别），保持现有约 760px 内容宽度。
- 所有预览卡片、列表行、表单控件统一使用 `rounded-ui`（8px）、`panel + border-border`，不使用卡片阴影。
- 将生成页独有的 18px padding 收敛为 16px；缩小音频列表行垂直 padding 与列表间距，同时保留 36px icon 点击区。
- 音频文件页预览卡片、错误文本和列表均使用同一主列宽度；列表 hover/selected 使用现有 `elevated` token，移除裸色 `bg-[#21262a]`。
- Toast 从 `rounded-xl`、重阴影和 `backdrop-blur` 收敛为 8px 圆角、细边框、面板背景与轻量阴影/无 blur，匹配扁平桌面工具风格。
- 不扩展 Home/VoiceClone 的功能或视觉内容，避免超出需求范围。

## 3. 优化滚动条和文本区滚动

修改：
- `desktop/src/renderer/src/styles/global.css`
- `desktop/src/renderer/src/routes/AppRoutes.jsx`

做法：
- `global.css` 继续只承载真正全局、无法由 utility 优雅表达的规则；新增一个用于真实滚动容器的语义类（例如 `app-scrollbar`）。
- 在主 `<main>` 上接入该类，保持仅主内容区滚动，不创建嵌套列表滚动区。
- 定制 WebKit/Electron 滚动条：8px 宽、透明/深色轨道、`border` 色滑块、hover 时 `border-strong`，不使用常态 primary 色。
- 追加 Firefox `scrollbar-width` / `scrollbar-color` 回退。
- textarea 使用同一滚动条样式，避免长文本时重新回到原生高亮滚动条。

## 4. 优化原生 select 的收起态

修改：
- `global.css`
- `VoiceGeneratePage.jsx`

做法：
- 保持原生 `<select>` 的键盘、无障碍和 Electron 平台行为，不为了视觉重写复杂 listbox。
- 为模型/发言人/语言选择器加语义 class：关闭默认 appearance，使用内嵌 SVG chevron，预留右侧空间；保留 40px 高度、8px 圆角、panel 背景、border 边界。
- hover 仅提高边框对比度；focus 维持 primary 边框与 ring。
- 对原生 option 设置可控范围内的深色背景与文字色。系统下拉面板的差异由 Electron/OS 承担，不强行依赖不稳定私有伪元素。
