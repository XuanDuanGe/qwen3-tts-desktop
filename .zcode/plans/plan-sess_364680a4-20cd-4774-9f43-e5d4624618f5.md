将前端改为 Tailwind-first 样式实现：启用现有 Tailwind 配置，并把布局、页面、控件、状态提示和音频列表的大部分 BEM CSS 迁移到 JSX 的 utility className。保留 `global.css` 仅用于 Tailwind 入口、Electron/窗口基础规则和最小全局 reset，不改动业务状态、IPC、路由行为或页面交互。

## 1. 正式启用 Tailwind

修改：
- `desktop/postcss.config.js`
- `desktop/tailwind.config.js`
- `desktop/src/renderer/src/styles/global.css`

做法：
- 在 PostCSS 中加入 `tailwindcss()`，保留 autoprefixer。
- 修正 Tailwind content 路径，保留实际存在的 `./index.html` 与 `./src/renderer/src/**/*.{js,jsx}`，移除不存在的 renderer HTML 路径。
- 在 `global.css` 加入 `@tailwind base; @tailwind components; @tailwind utilities;`。
- 将全局 CSS 收缩为根窗口尺寸、body 背景/字体/overflow、button 字体继承等基础规则；组件级 BEM 样式、页面布局样式、按钮样式、toast 样式全部迁移到 JSX utility className。
- 在 Tailwind theme 中补充状态灯所需的统一 pulse keyframes/animation，避免继续在 global.css 中维护组件动画。

## 2. 重构应用壳与窗口布局

修改：
- `desktop/src/renderer/src/routes/AppRoutes.jsx`
- `desktop/src/renderer/src/layout/TitleBar.jsx`
- `desktop/src/renderer/src/layout/Sidebar.jsx`
- `desktop/src/renderer/src/layout/StatusBar.jsx`

迁移内容：
- `.app-shell`、主体区、内容滚动区改为 Tailwind flex/min-height/overflow/background 工具类。
- TitleBar 的深色背景、边框、品牌标记、窗口按钮 hover/focus，以及 Electron 必须的 `-webkit-app-region: drag/no-drag` 使用 utility/arbitrary property class；保留窗口控制调用逻辑。
- Sidebar 的宽度、导航间距、品牌区、NavLink 默认/hover/active 状态改为 utility class，补上当前 BEM CSS 中缺失的 active 视觉状态。
