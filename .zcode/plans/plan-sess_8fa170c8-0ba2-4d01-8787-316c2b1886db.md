已定位到窗口栏未渲染的根因：组件已正确挂载在 `AppRoutes` 中，样式也没有隐藏它；实际问题是预加载脚本没有被加载，导致渲染端初始调用 `window.api.isWindowMaximized()` 时 `window.api` 不存在并抛错。

原因是 `vite-plugin-electron` 在当前 ESM 项目中生成预加载产物为 `desktop/dist-electron/index.mjs`，但主进程仍指向不存在的 `../preload/index.js`。这会使 contextBridge 完全没有执行，进而影响标题栏和首页 IPC。

我会进行最小修复：

1. 将主进程 `BrowserWindow` 的 `preload` 路径改为与插件实际生成的 `dist-electron/index.mjs` 相同的路径。
2. 在窗口控制 API 与 `TitleBar` 初始化中加入最小的可控失败处理，避免预加载在未来失效时导致整个 React 界面崩溃；正常加载时不会改变任何交互。
3. 运行 ESLint 和根目录 `pnpm dev` 验证：检查预加载加载日志、渲染进程无 `window.api` 异常，标题栏可见。验证后停止开发进程，不执行构建。

不增加新依赖，不改变拖拽/按钮行为，也不新增无关 UI。
